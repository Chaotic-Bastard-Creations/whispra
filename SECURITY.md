## Supported Versions

Whispra is currently in **active development** and has not yet released a stable version.

| Version          | Supported          |
|------------------|--------------------|
| `main` branch    | :white_check_mark: |
| Development builds | :white_check_mark: |
| Older versions   | :x:                |

> **Note**: Until the first stable release (v1.0.0), only the `main` branch receives security updates.

## Reporting a Vulnerability

We take security and privacy very seriously.

**Please report any security vulnerabilities responsibly** by emailing:

**security@chaoticbastard.com**

### What to include:
- Clear description of the issue
- Steps to reproduce the vulnerability
- Potential impact
- Any suggested mitigation (optional)

### Our Response Timeline:
- **Acknowledgment**: Within 48 hours
- **Initial update**: Within 7 days
- Full resolution as quickly as possible

We kindly request that you **do not disclose the vulnerability publicly** until we have released a fix.

Thank you for helping keep Whispra secure.
